# Local media (mirrored from the live WordPress site)

All site imagery is stored here so the app does not depend on
`advocatesforhealthandrights.org` after that host is taken down.

Web path: `/assets/img/...` via `Url::asset('img/...')`  
Project shortcut: repo root `assets/` → `public/assets/`

## Folders

| Folder | Contents |
|--------|----------|
| `brand/` | Logo and favicon marks |
| `hero/` | Home hero slideshow |
| `presence/` | Home filmstrip / about teaser |
| `programs/` | Program photography |
| `announcements/` / `flyers/` | Poster / flyer strip |
| `sdg/` | SDG badge artwork |
| `gallery/` | Gallery photography (IMG_/DSC_/OL_) |
| `people/` | Board / advisory portraits |
| `about/` | About page photography |
| `misc/` | Other mirrored campaign / event photos |

Homepage and public pages should only reference these local files.
